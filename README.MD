# Fastfetch Config

My personal fastfetch configuration, based on a modified fastcat theme with a customized fastfetch logo.

Originally made on Omarchy, but it should work on any Linux distro with fastfetch installed.

## Features

- Modified fastcat-based theme
- Custom fastfetch logo
- Clean and minimal layout
- Works across distros (font availability may affect appearance)

## Requirements

- `fastfetch`
- A terminal that supports colors and Unicode
- (Optional) Nerd Font or similar for best icon support
